# Alpha Efficiency Calculator

An interactive, open-source web application for calculating gross alpha counting efficiency based on an analytical framework that integrates alpha self-absorption and backscattering models.

## Features
* **Efficiency Calculator:** Computes total efficiency, direct escape probability, and backscattering components across different kinetic regions (Region A, B, and C).
* **Matrix Database:** Interactive lookup and editing library for effective alpha-particle mass ranges ($R_{mix}$) simulated from SRIM-2013, with automatic local CSV persistence.
* **Customizable Parameters:** Allows adjusting sample dimensions, mass, detector geometry, and alpha-particle energies.
